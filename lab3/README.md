第一部分（响应时间）：读取 1000/1050/1100/1150/1200 线程、10 秒升压、每线程 2 次循环；写入 1000/1100/1200/1300 线程、10 秒升压、每线程 1 次循环，共 9 组、15600 次请求。

第二部分（吞吐上限）：读写各 20/50/100/200 线程、5 秒升压，线程连续发送请求；读取每组 30000 次、写入每组 10000 次，共 8 组、160000 次请求。读取最初按每组 10000 次执行，稳态过短，改为 30000 次重跑，第一次结果未纳入统计。

两部分共 17 组、175600 次请求，断言失败 0 次。JTL 内容未做任何修改，文件名标明读写类型与参数。
